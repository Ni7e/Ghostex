# Commands

## Useful Terminal Hotkeys

- `Ctrl+A` - jump to start of line
- `Ctrl+E` - jump to end of line
- `Ctrl+B` - move back one character
- `Ctrl+F` - move forward one character
- `Alt+B` - move back one word
- `Alt+F` - move forward one word
- `Ctrl+U` - delete from cursor to start of line
- `Ctrl+K` - delete from cursor to end of line
- `Ctrl+W` - delete word before cursor
- `Alt+D` - delete word after cursor
- `Ctrl+Y` - paste/yank last deleted text
- `Alt+Y` - cycle older deleted text after `Ctrl+Y`
- `Ctrl+_` - undo last edit
- `Ctrl+L` - clear screen, keep current command
- `Ctrl+C` - cancel current command or process
- `Ctrl+D` - delete character, or exit shell on empty line
- `Ctrl+Z` - suspend current process
- `fg` - resume suspended process in foreground
- `Ctrl+R` - reverse search command history
- `Ctrl+G` - cancel history search
- `Ctrl+P` - previous history command
- `Ctrl+N` - next history command
- `Alt+.` - insert last argument from previous command
- `Ctrl+J` - accept/submit line, like Enter
- `Ctrl+M` - Enter/carriage return
- `Ctrl+O` - run current history command and load next one
- `Ctrl+T` - swap current character with previous
- `Alt+T` - swap current word with previous
- `Alt+U` - uppercase word from cursor
- `Alt+L` - lowercase word from cursor
- `Alt+C` - capitalize word from cursor
- `Ctrl+V` - insert next key literally
- `Ctrl+Q` - resume terminal output if it got frozen
- `Ctrl+S` - often freezes output, avoid unless using flow control
- `Ctrl+X Ctrl+E` - edit current command in `$EDITOR`
- `Tab` - autocomplete command/path
- `Esc .` - same as `Alt+.`, useful when Alt is awkward
