Ask your agent for an HTML explainer

Use this starter as a prompt target. Ask an agent to replace it with a focused HTML document that explains a feature, workflow, bug, decision, or research topic in a way your team can scan and discuss.

1. Ask

Tell your agent what to explain

Name the topic, audience, and level of detail. Ask for sections, examples, diagrams, tables, or callouts when they help.

2. Review

Open the rendered document

Read it in Docs like a real page. Check whether the structure, labels, and examples make the explanation clear.

3. Annotate

Use Agentation for feedback

Click Annotate in the Docs header, point at the exact paragraph, diagram, or layout issue, and leave notes your agent can act on.

Prompt to try

Create an HTML document in docs/ that explains <topic> for <audience>. Make it dark, polished, and easy to scan. Use inline styles, clear sections, practical examples, and a small diagram or table if it helps. Keep it self-contained so I can annotate it in Ghostex Docs with Agentation.

Good requests are specific. Ask for the job the document should do: onboard a teammate, explain a tradeoff, compare options, summarize an incident, or teach a workflow.

Good annotations are precise. Mark the part that is confusing, missing, too dense, or visually off, then ask your agent to revise this HTML file.
